### Notes

- All screenshots should be in **PNG** format.
- Capture at a standard resolution (e.g. 1920×1080 or 1280×720) on a desktop system.
- Use the default theme (dark) and English locale for consistency.
- If a screenshot shows a specific data state, use the built-in demo data.
- Replace placeholder images with real captures before publishing.
